# Impeccable Design Context File
# Project Target: finsave-ai (Fintech Trust Platform)

## Tech Stack & Component Constraints
- Core Framework: React, TypeScript, Vite, Tailwind CSS
- Base Components: shadcn/ui + Recharts (Customized, no raw defaults)
- Money Format: Decimals/Integers (No raw floats in UI views)

## Context Configuration
- Interface Mode: Product Lane (High-density Fintech Dashboard, multi-account ledger)
- Brand Anchor: Solid, premium, professional, trustworthy MSME aesthetic

## Strict Design System Overrides (Anti-Slop Logic)
- FONT BLOCKLIST: Active. Do not rely on unconfigured Inter or system sans-serif defaults. Enforce rigid, deliberate type hierarchies with proportional line-heights.
- VISUAL TROPE BANS: 
  - Absolute ban on glassmorphism, background blurs (`backdrop-blur`), and container transparency.
  - Absolute ban on neon color schemes and blue-to-purple linear backgrounds.
  - Absolute ban on nested cards (no card-inside-a-card container stacking).
- LAYOUT ENGINE: Force a strict 8px incremental spacing rhythm (`p-2`, `p-4`, `p-6`, `p-8` / `gap-4`). Every dashboard container must use an explicit corner radius of `rounded-2xl` to `rounded-3xl` (16px–20px) with custom soft, muted shadows.
- SIDEBAR RULE: Must retain a solid dark navy background with crisp white typography and micro-interactions.
- MOTION ENGINE: Restrained. Use linear micro-transitions for currency/state shifts. Enforce media query reductions (`motion-reduce:transition-none`).

## Commands Reference Mapping
When a command keyword is issued in conversational text, the agent must trigger the associated Impeccable sub-routine:
- polish: Scan target layout code, recalculate vertical alignment rhythm to 8px intervals, strip generic AI layout fluff, and upgrade borders to custom soft-neutrals.
- audit: Evaluate the document against 59 deterministic detector rules for frontend design slop (checking color contrast, line-heights, and font scale drift).
- critique: Evaluate the information density of the current page (e.g., verifying multi-account identifiers like 'Bank of Kigali' or 'MTN MoMo' are distinctly visible and not clumped together).
